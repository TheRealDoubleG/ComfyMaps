# ComfyMaps Changelog

## 0.1 Beta – 28.09.2026
- Initial Comfy Suite world-map addon for WoW Forever.
- Added scale, opacity, moving opacity and decorative-border controls.
- Added unlock/drag handle, remembered position and reset.
- Added player/cursor coordinate overlay.
- Added ComfyGatherer world-map node integration.
- Added category-based map settings and Blizzard AddOns settings registration.
